# 使用说明 · 烟雨观星 73536+ HAR 存档工具

本工具将**自己账号的 HAR 存档下载响应**解析为 JSON，并在本地打开观星网页版。无需配置 ADB、Root、模拟器内存扫描或手工密钥文件。

## 一、运行条件

- **Python 3.8 或更新版本**，建议 Python 3.11。
- Windows PowerShell / CMD 或其他支持 Python 的命令行终端。
- 一个可使用的默认浏览器。
- 由 ProxyPin、mitmproxy 等工具导出的完整 `.har` 文件。

Python 可从 [python.org](https://www.python.org/downloads/) 安装。Windows 安装时可以勾选“Add Python to PATH”，随后执行：

```powershell
python --version
```

核心解析使用标准库，不要求安装额外 Python 包；测试用 pytest 为可选开发依赖。

## 二、启动与选择角色

在仓库目录执行：

```powershell
python .\run.py
```

菜单会按更新时间列出已解析的角色：

```text
烟雨观星 · HAR 存档工具 v1.1.0

已解析角色（默认最新）：
  [1] 示例角色甲  android·s53  2026-10-31 15:00  217 字段
  [2] 示例角色乙  ios·s26      2026-10-30 20:10  221 字段

  [n] 解析 HAR
  [q] 退出

请选择（直接回车默认第一个角色）：
```

| 输入 | 执行操作 |
| --- | --- |
| `1`、`2` …… | 打开所选角色的网页版，自动载入其存档 |
| 直接回车 | 已有记录时打开第一个角色 |
| `n` | 提示输入 HAR 路径，成功后保存并打开网页版 |
| `q` | 退出工具 |

未解析过任何角色时，列表为空，只需按 `n` 导入即可。

## 三、获取适用的 HAR

**关键要求：抓到属于自己账号的登录密钥信息以及 `download3`“下载存档”响应。** 只有登录或只有上传存档的 HAR 并不足够。

推荐步骤：

1. 在游戏中退出当前登录，返回登录界面。
2. 启动 [ProxyPin](https://github.com/wanghongenpin/proxypin) 或其他 HAR 抓包工具，开始记录本人账号的相关网络请求。
3. 重新登录并进入对应区服；保留带 `k` 响应头的会话记录。
4. 在游戏提供的功能中执行一次**下载存档**，确认捕获的请求头中包含 `command=download3`。
5. 停止抓包，导出完整的 `.har` 文件，传到运行 Python 的电脑。

不需要为了解密额外执行“上传存档”；仅 `upload3` 不能作为本项目的完整存档来源。

抓包涉及账号、会话及游戏数据，应遵守游戏服务条款和适用法律，**只处理自己获授权的数据**；在工具之外妥善保管 HAR，切勿分享真实抓包。

### HAR 版本要求

| 存档版本 | 结果 |
| --- | --- |
| 73536 | 已有真实格式验证 |
| 73570 | 已有真实格式验证 |
| 不低于 73536 的其他版本 | 尝试当前 `download3` 解密流程；通过完整校验才算成功 |
| 73492 及以下 | 直接拒绝，明确提示不支持 |
| 不存在 `download3` | 无可解析的下载存档，提示失败 |

“版本 ≥73536”是**允许尝试解析的范围**，并非未来所有版本均可无条件解密。

## 四、解析 HAR

在交互菜单输入 `n`，然后粘贴文件完整路径：

```text
请输入 HAR 文件路径（可拖入文件，q 取消）：
C:\Users\YourName\Downloads\save.har
```

成功后工具会保存该角色当前存档，并打开网页版自动载入。路径包含空格时可带引号，也可以从 Windows 文件管理器拖拽到终端。

命令行直达方式：

```powershell
python .\run.py capture "C:\Users\YourName\Downloads\save.har"
```

该方式只完成解密和输出，不会自动弹出网页版。

如需把新解析数据保存到指定根目录：

```powershell
python .\run.py capture ".\save.har" --outdir "D:\MySaves"
```

## 五、输出文件与覆盖规则

默认输出目录：

```text
output/
  _har_only/
    android-s53-<账号摘要>/
      dat.json
      dat.db
      dat.meta.json
```

| 文件 | 含义及建议用途 |
| --- | --- |
| `dat.json` | 已解密的存档对象，网页自动载入使用 |
| `dat.db` | 为网页与兼容工具重新生成的 v1.8 SQLite 格式，不是客户端原始密文存档 |
| `dat.meta.json` | 角色、账号、区服、版本、HAR 时间及导出时间等元信息 |

- 新导入的同一账号、平台、区服，使用固定目录，**仅保留一份当前导出结果**。
- 新 HAR 必须完整解密及写盘成功后才会替换之前的当前记录。
- 当双方下载时间可比较、且新 HAR 较旧时，会拒绝覆盖以避免角色进度回退。
- 菜单可能兼容显示已有旧目录中的历史记录；旧目录文件不会被自动清除。

**`dat.db` 是兼容导出文件，不能直接当作可回填游戏客户端的数据。** 如果只想在网页版观星，直接通过菜单选择角色即可。

## 六、网页版的使用

选择角色后，工具使用系统默认浏览器打开本地网页，并把对应 `dat.json` 自动载入浏览器存储。网页版提供角色信息、洗髓、装备及相关模拟功能；具体结果以网页版当前实现为准。

如无法自动打开，可尝试直接打开 `web/index.html`，通过网页的“导入数据”手动选择工具生成的 `dat.db`。直接打开主页与自动载入已有角色不是同一操作。

网站数据写入浏览器本地存储，**压缩不等于加密**。共享电脑使用后应留意浏览器中的个人存档信息。

## 七、常见问题

| 现象 | 排查方式 |
| --- | --- |
| 提示未找到 `download3` | 确认已执行游戏中的“下载存档”，并导出包含该响应的完整 HAR |
| 提示找不到 `k` | 从退出登录前开始抓包，保留登录/会话响应；不要只导出下载那一条 |
| `extra` 无法恢复密码段 | 检查 HAR 是否缺失字段、响应是否属于同一账号或抓包是否完整 |
| 会话层解密失败 | 检查 `session`、`startedDateTime` 是否存在以及当前版本协议是否变化 |
| 内层解密或 JSON 校验失败 | 可能是未收录渠道后缀、账号错配、HAR 不完整或新版本变更 |
| 提示版本低于 73536 | 此类 HAR 不支持，无需反复尝试 |
| 提示旧 HAR 不允许覆盖 | 当前角色已有采集时间更晚的记录；选择正确的新 HAR |
| 网页未自动打开 | 检查默认浏览器和 `web/index.html`；必要时手动导入 `dat.db` |
| 切换安装目录后看不到角色 | 角色数据保存在本机 `output/`，克隆代码不会自动同步个人数据 |

需要查看更完整的实现，请阅读 [解密原理](README.md) 和 [73536+ 适配说明](../本次更新内容.md)。

## 八、数据安全与相关项目

HAR、`dat.json`、`dat.db`、`dat.meta.json` 以及自动载入页面均可能包含个人账号或游戏数据。**不要把它们提交到公开 GitHub 仓库，也不要直接发送给陌生人。**
